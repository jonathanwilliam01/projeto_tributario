# Atalhos Tributário

O Atalhos Tributário agora faz parte do [Atalhos Embras](https://atalhos-embras.vercel.app/) ([repositório](https://github.com/jonathanwilliam01/atalhos_embras)).

Este projeto só redireciona https://projeto-tributario.vercel.app/ para lá:

- `public/index.html` leva a tela aberta (`#egov`, `#itbi`...) e os favoritos e recentes salvos neste endereço.
- `public/ngsw-worker.js` desinstala o app antigo de quem o instalou ou tem o service worker ativo.

O código do app até a versão V3.26.10.06 continua no histórico do git.
